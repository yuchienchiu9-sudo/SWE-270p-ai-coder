GroupChat is a simulated social networking group chat application with Python and Streamlit. No remote messaging or external service is required.

Requirements:
1. Create named groups with descriptions and unique identifiers.
2. Join existing groups and list a user's memberships.
3. Post text messages to joined groups with timestamps.
4. Reject empty messages and posting to groups the user has not joined.
5. List group chat history in chronological order.
6. Simulate attachment messages using filename metadata (no file uploads).
7. Provide Groups, Chat, and Members tabs.
